# Inkseal (ตราหมึก)

**ประทับตราผลงานของคุณด้วยลายมือตัวเอง ลายเซ็นดิจิทัลที่ปลอมไม่ได้ และรหัสผู้สร้างล่องหน**
ฟรี โอเพนซอร์ส และทำงานในเครื่องของคุณทั้งหมด ไม่มีการอัปโหลดรูปไปไหน

**▶ ใช้งานได้เลยที่: https://ronsuthlor3-lab.github.io/inkseal/**

## ทำอะไรได้บ้าง

| ชั้นการปกป้อง | คืออะไร | ได้อะไร |
|---|---|---|
| ✍️ **ลายเซ็นลายมือ** | เซ็นด้วยเมาส์ ปากกา หรือนิ้ว เส้นหนาบางตามแรงกดหรือความเร็วมือ แล้ววางลงบนผลงาน | เห็นชัดว่าเป็นของใคร กันการก๊อปแบบมักง่าย |
| 🔐 **ลายเซ็นดิจิทัล** (Ed25519) | ชื่อ ชื่องาน สิทธิ์การใช้งาน และ hash ของรูป ถูกเซ็นด้วยกุญแจลับของคุณ แล้วฝังไว้ในไฟล์ | **ปลอมไม่ได้** ถ้ามีคนแก้แม้แต่พิกเซลเดียว การตรวจสอบจะขึ้นว่า "ถูกแก้ไข" |
| 👻 **รหัสผู้สร้างล่องหน** | ซ่อนรหัสประจำตัวไว้ในพิกเซล ตามองไม่เห็น | ยังอยู่แม้มีคนลบข้อมูลไฟล์ หรือเซฟใหม่เป็น JPEG |
| ⏱️ **หลักฐานเวลาสาธารณะ** (เลือกได้) | บันทึก hash ของไฟล์ลงบล็อกเชน Bitcoin ผ่าน OpenTimestamps | พิสูจน์ได้ว่าคุณมีไฟล์นี้ในเวลานั้น ก่อนคนอื่น |

ใครก็เปิดหน้า **ตรวจสอบ** ได้ จะเห็นว่าใครเป็นคนประทับตรา รูปถูกแก้ไขหรือไม่ และรหัสล่องหนตรงกับผู้ประทับตราหรือไม่
ถ้าโจรลบตราแล้วประทับตราของตัวเองทับ ระบบจะขึ้นคำเตือนว่า **รหัสไม่ตรงกัน**

## ข้อจำกัดที่ต้องรู้

ไม่มีเทคโนโลยีไหนกันการขโมยได้ 100% สิ่งที่ตามองเห็นได้ก็แคปหน้าจอได้เสมอ
Inkseal ไม่ได้ล็อกไฟล์ แต่ทำให้ **พิสูจน์ความเป็นเจ้าของได้** และ **จับได้เมื่อมีการปลอมแปลง**

- ลายเซ็นดิจิทัล **ถูกลบออกได้** แต่ **ปลอมไม่ได้**
- ลายน้ำล่องหนทนการเซฟซ้ำและการบีบอัด JPEG (ประมาณคุณภาพ 60–75 ขึ้นไป) แต่ **ไม่ทน** การครอป ย่อขนาด หมุน หรือใส่ฟิลเตอร์หนักๆ
- พื้นที่ขาวจัดหรือดำจัด (เช่น พื้นหลังขาวล้วน) ฝังลายน้ำไม่ได้ ระบบจะข้ามให้อัตโนมัติ
- เวลา "ประทับตราเมื่อ" มาจากนาฬิกาในเครื่องผู้สร้าง ไฟล์ `.ots` เท่านั้นที่พิสูจน์เวลาได้จริง
- ถ้ามีคนได้ทั้งไฟล์ตัวตน **และ** รหัสผ่านของคุณ เขาจะเซ็นในนามคุณได้ เก็บทั้งสองอย่างให้ดี

## วิธีใช้

### ผ่านเว็บ (ไม่ต้องติดตั้ง)

1. **ตัวตน**: สร้างตัวตน จะได้ไฟล์ `inkseal-identity-ชื่อ.json` **สำรองไว้หลายที่**
2. **ลายเซ็น**: เซ็นในกรอบแล้วกดบันทึก
3. **ประทับตรา**: ลากรูปมาวาง จัดตำแหน่งลายเซ็น ใส่ชื่อผลงาน แล้วกด "ประทับตราและดาวน์โหลด"
4. **ตรวจสอบ**: ลากรูปไหนก็ได้มาวางเพื่อตรวจ

ใช้กับ Chrome/Edge 137 ขึ้นไป, Firefox 129 ขึ้นไป หรือ Safari 17 ขึ้นไป

### ผ่าน command line (ประทับตราทีละหลายไฟล์)

ต้องมี Node.js 20 ขึ้นไป

```bash
npm install
```

```bash
node cli/inkseal.js keygen --name "ชื่อของคุณ" --contact "instagram.com/you"
```

```bash
node cli/inkseal.js seal ./ผลงาน --id me.inkseal-id.json --signature ลายเซ็น.png --timestamp
```

```bash
node cli/inkseal.js verify ./ผลงาน/sunset.sealed.png
```

## เปิดให้คนอื่นใช้ผ่าน GitHub Pages

1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub
2. ไปที่ **Settings → Pages** ตั้ง **Source: Deploy from a branch** เลือก branch `main` โฟลเดอร์ `/ (root)`
3. แอปจะออนไลน์ที่ `https://<ชื่อคุณ>.github.io/<ชื่อ repo>/`
